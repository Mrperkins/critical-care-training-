# Critical Care Physiology

Interactive trainers on one simulated patient, with 3D anatomy.

- Critical Care Physiology (ventilator, blood gas, labs, cells, arterial line & CVP): https://mrperkins.github.io/critical-care-training-/
- Infarct Atlas (coronary territories and ECG localisation) is now part of the main app: Cardiac → Coronaries & ECG (`?module=heart&view=coronary`; the old /infarct-atlas/ link redirects there). Source: `app/src/infarct/`, asset pipeline `app/pipeline/build-coronary.ts`.
